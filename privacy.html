QudadFlow Translator Privacy Policy

Version 0.6.0 · Effective date: October 21, 2026

This policy explains how QudadFlow Translator processes information when you use the Microsoft Edge extension. Developer and privacy contact: lcf1249288484@outlook.com.

Information processed

After you start a translation, the extension reads your selected text or visible text from the current webpage. It sends the text, source and target languages, and the authentication and configuration fields required by your selected API directly to the endpoint you configure. Depending on the API, the request can also include a model name, translation instructions, paragraph markers, and custom request fields or headers.

The extension does not automatically collect browsing history or translate pages in the background. Page extraction skips editable controls, hidden content, extension translations, and content marked to be excluded. Text that you explicitly select can still be sent when you request selection translation.

Document reader

The document reader in version 0.6.0 supports PDF, DOCX, TXT, and Markdown. Files you choose or drop are parsed locally using bundled libraries. When you open a remote document URL, the extension requests access to that source's HTTP(S) scheme and host on all ports, then downloads the file into the browser. Where browser rules permit, this download may include that source site's login cookies. Your translation API key is not attached to document downloads. Local file selection does not require broad file-URL access.

Opening or navigating a document does not start translation. After you click a translate button, extracted text and the translation request settings are sent to your configured API; original PDF or DOCX file bytes and PDF passwords are not uploaded to it. Embedded images are sent only through the optional AI workflow described below. Source URLs are kept in the reader's temporary input, not sent as translation context. Passwords, if requested by an encrypted PDF, are used only for local decryption. JavaScript and external resources embedded in documents are not executed or fetched.

The open reader holds file data, extracted text, and translations in tab memory. Closing or replacing the document clears that reader state. Successful text translations may also remain in the bounded service-worker memory cache described below. No document library or translation history is saved by the extension. If you export bilingual TXT, the browser saves that file to your chosen download location; delete it there when no longer needed.

Optional AI picture/chart workflow (0.6.0)

Traditional translation APIs and AI can both translate document body text. The separate workflow at the bottom can extract PDF raster regions or Word images, or capture a manually selected PDF region or whole page. Extraction and previews happen locally and do not call an API. Only after you click an analysis button does the extension send the chosen image(s), target language, analysis instructions, model and authentication fields directly to the current or separately saved OpenAI-compatible AI endpoint you select. A whole-page capture includes the visible content of that page as an image. The original document file and its password are not sent.

Extracted images, previews and AI results are held in the reader's tab memory and bypass the service-worker text cache. Replacing or closing the document clears them; changing the configuration clears analysis results. Images you download and bilingual TXT exports remain in your chosen download folder. The AI provider applies its own retention terms. Choose the image region and endpoint with care, and verify AI text and chart explanations against the original.

Translation providers

QudadFlow Translator does not operate a translation server or proxy. You choose the API provider and endpoint, including Google Cloud Translation, DeepL, Microsoft Translator, an OpenAI-compatible service, or a custom JSON service. That provider receives your translation requests and applies its own privacy, retention, security, and billing terms. Choose a trusted endpoint; use HTTPS for remote services.

Provider privacy information: Google, DeepL, and Microsoft. For other endpoints, consult the provider you configure.

Local storage and API keys

You can save up to 20 named API configurations, including their keys, endpoints, headers, and preferences, in browser-local extension storage. The existing configured connection is preserved when this feature is first used. Selecting a scheme for editing does not apply it until you save; the popup can apply a saved scheme directly. Deleting the active scheme also clears its live connection, while other schemes keep their own credentials. Saved configurations are not synced to GitHub or to the developer. They are configuration history, not translation history.

Your API key, endpoint, model, language preferences, and custom API settings are saved in the browser's extension local storage. They are not synchronized by this extension and are not sent to the developer. API keys and custom authentication fields are sent to your configured endpoint to authenticate requests. Switching providers in the settings page keeps separate temporary connection drafts and does not automatically reuse another provider's key.

Translation results are displayed in the current page and are not saved in extension storage. Immersive translations are inserted into the webpage, where the webpage's scripts may be able to read them. Restore the original page or reload it to remove the inserted translations.

For faster repeated reading, the service worker may keep successful source-and-result pairs in memory, with a five-minute reuse window and a limit of 128 entries and 250,000 combined characters. Expired entries are removed on the next cache lookup. This cache is not written to disk, is cleared when settings change, and may disappear when the browser stops the worker. Connection tests bypass the cache. No persistent translation history is maintained by the extension.

Optional key-free MyMemory trial

If you explicitly enable the MyMemory basic trial, extracted text is sent via HTTPS query parameters to api.mymemory.translated.net, without an API key or source-site cookies. Source language must be chosen explicitly. The service provides translation-memory matches and machine translation, with a typical anonymous quota of 5,000 characters/day. Its terms describe long-term retention of submitted segments and third-party machine translation processing. Use non-private short samples, and review its terms and privacy policy and usage limits. The extension only calls its GET translation endpoint, never contribution/upload endpoints, and does not silently switch your configured provider. No unlimited free service is promised.

Permissions

activeTab and scripting access the current page and inject the bundled translation interface after an extension action. Storage saves your API settings and preferences locally. Context menus provide translation commands in the browser's context menu. Optional host access permits requests to the HTTP(S) API domain you configure. If you enable the selection button for a site, Edge registers the bundled content script for that site's HTTP(S) scheme and host on all ports. The script only shows a button after text is selected; selecting text alone does not send it. Disabling the setting stops the button on open pages and unregisters future loading. Edge retains the granted permission until you revoke it in extension settings.

Advertising, analytics, and remote code

The extension contains no advertising, tracking, analytics, or telemetry. The developer does not sell personal information. All executable extension code is bundled locally. API responses are handled as text data and are never executed as code.

Your choices and deletion

You can change your endpoint and credentials in the settings page, revoke site permissions through Edge's extension settings, restore translated pages, or remove the extension. Removing it deletes its local extension storage. These actions do not delete data already retained by an API provider; contact that provider about deletion and other privacy requests.
