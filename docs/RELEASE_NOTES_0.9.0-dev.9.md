# QudadFlow Translator 0.9.0-dev.9（本地开发版）

## Team / Business 授权说明

- ChatGPT 计划入口不按套餐名称在插件内阻止 Team / Business 成员。每位成员使用自己的账号授权；插件不会共享管理员账号或 API Key。
- 在现有“API 方案与模型”分区显示组织策略和额度资格说明。`3p_delegated_access_policy_denied` 引导组织管理员统一核查；`subscription_sharing_user_not_eligible` 明确停止重复授权。错误码和经过筛选的上游 Request ID 会在设置页保留；普通成员无需管理权限，默认机器翻译仍可免配置使用。
- 管理员放行只解决组织策略，不能在插件内承诺 Team / Business 成员的额度可用于官方开源接入。官方文档目前明确列出符合资格的 Plus / Pro。每位成员是否获得计划使用权限，以官方授权及真实 Responses 连接测试为准。

## 验证

- 隔离 Edge 设置页 18/18 项通过，使用合成账号和本机程序响应，覆盖组织策略拒绝、模拟获准的 Team 成员、额度资格拒绝、旧 API 配置不被暗中覆盖以及窄屏布局。
- 本机宿主 29/29 项通过；纯本地快速检查与 269 个运行文件、37 个脚本语法和依赖校验通过。之前开发版的网页、文档、论文、PDF 等广泛回归记录保持原样。
- 尚未在 OpenAI 管理台修改组织策略，也未用普通 Team 成员账号验证真实第三方额度资格。真实个人 Pro 账号的模型读取和固定短句推理记录属于 0.9.0-dev.8。

这是本地开发版，尚未发布到浏览器商店。步骤与边界见 [ChatGPT 登录说明](CHATGPT_LOGIN.md)。
