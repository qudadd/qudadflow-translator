QudadFlow Translator 以网页沉浸式双语阅读和划词翻译为核心，支持 PDF、Word DOCX、TXT、Markdown 阅读，以及可选的 AI 论文问答和图表分析。使用自己的翻译 API，操作界面为简体中文，名称统一使用英文。

0.8.15 新增与改进
弹窗、文档阅读器及论文工作台可自动读取当前 API 的上游模型，支持就地刷新／取消和共享选择，下拉框仅显示模型 ID。API 方案只在设置中新增和切换。PDF 支持逐页／连续阅读，强化按图注编号提取图表、可复制文字表格及总览内的 AI 补充识别，工作台收缩为紧凑分栏。

网页沉浸式与就近划词翻译
保留原文、链接及页面结构，译文紧随原段落。优先处理当前视区，随滚动、展开及动态内容补充，可信识别为目标语言的文字跳过。按站点启用划词按钮后，选择文字再点击附近的“翻译”；单纯划选不会发送请求。可自定义译文颜色，快捷键默认 Shift+A，可输入、录制、保存、恢复或停用，输入框和编辑器保留正常操作。

自己的 API，当前连接中的模型
支持 Google Cloud Translation、DeepL、Microsoft Translator、OpenAI 兼容 Chat Completions／Responses 与自定义 JSON API。在设置中最多保存 20 个具名连接；所有阅读页只切换当前连接的模型。模型发现不发送网页文字，按连接保存有上限的本地列表，错误或空列表保留当前选择，不自动盲选首个模型。不提供模型列表的上游可在设置中手填其文档中的 ID；名称不能证明视觉能力。MyMemory 可供有限免 Key 试用，匿名通常约 5,000 字符／天。

翻译和 AI 请求不设扩展固定超时，手动停止或真实 HTTP／网络／流错误时结束。服务商限制仍适用，文档和图片下载保留资源保护。

PDF、Word、TXT 与 Markdown
通过独立阅读器打开本地文件或已授权文档链接，可选沉浸原位、原版左右对照或段落对照。PDF 保留页面比例和图表位置，不能容纳的长译文提供完整查看入口；支持逐页和连续阅读。可翻译当前页／全文、停止继续并导出双语 TXT。Word 版式可能与 Microsoft Word 不同。文件最大 25 MB，PDF／渲染后的 Word 最多 300 页；扫描正文替换需外部 OCR，暂不导出保持版式的译后 PDF／DOCX。

论文图表、可复制表格与 AI 问答
网页采用可移动、缩放的论文问答窗，文档使用底部紧凑图表工作台。结合图注编号及结构识别图、图片表格与原生文字表格。PDF 支持本页／全文提取，结合绘图坐标、跨页续表和有序图例，减少装饰图片与重复裁剪。网页合并同图重复版本，保留不同分图；符合条件的完整表格链接沿用原论文站点会话读取。文字表格可本地复制、导出 Markdown／TSV。可搜索、全选图表、批量载入可用高清原图，再结合正文提问。

PDF 漏提取时，在“图表总览 → AI 补充识别”选择页码，主动发送页面图文，核对候选裁剪后才确认加入。普通与 AI 结果共享身份／重叠去重，续表保留跨页片段。图片表格可主动调用视觉 AI 转录为可复制格式。打开文件、本地提取、选择及载入本身不调用 AI；识别为启发式，可能需要人工修正。

可选 AI 解释图表，生成可下载的 Python／R 复现草稿，代码不会执行。支持可编辑 Skill 提示模板和默认关闭、可在设置中导出的跨页笔记本记忆。正文不设固定字数截断，浏览器、模型上下文和资源限制仍适用。AI 输出、数字表格及代码均需核对。

数据与权限
文件和表格 HTML 在本地解析；仅主动请求的文字、所选图片及已启用的研究上下文直接发送到所配置的服务商。模型读取使用保存的 API，不附带网页正文。Key 和设置存于扩展本地，没有开发者翻译代理、广告、遥测或远程执行代码。网站／API 按需授权，首次站点提示同意后隐藏；可主动一次授权所有网站减少提示。浏览器内部页及内置 PDF 视图使用独立扩展入口。
