# QudadFlow Translator 0.9.7

2026-11-06，本地开发构建。修复 PMC 图片识别与论文问答，并保存网页论文工作区。尚未创建本版 GitHub Release 或提交 Chrome/Edge 商店；0.9.6 发布记录仍单独保留。

- PMC 缩放查看器链接的查询参数可能以 `.jpg` 结尾，但返回的是 HTML。原图识别改为检查 URL 路径，使用页面提供的真实图片来源；正式图号标题与独立图注合并。PMC9529820 Figure 1 的原图地址和图注已在实际页面核对，公开原图能够打开。旧版临时提取缓存会重新解析，避免沿用错误地址。
- 问答跳过选中但未载入或载入失败的图片；正文、文字表格和可用原图继续参与。窗口、导出记录和请求材料明确列出未提供图片的图号及原因，防止模型把图注当成已经查看的图片。保留选择与重试入口。图表专门的批量分析仍要求先载入原图；提供方 HTTP/流式错误继续显示，停止仍取消请求。
- 同一完整网页 URL 再次打开论文入口，优先聚焦已有窗口；关闭后自动恢复材料编辑、问题草稿、对话、图片和选择、图表解读、Python/R 代码、搜索及工作台视图。普通正文锚点不另建记录，查询参数及应用路由继续隔离。原文刷新后重新打开入口会安全重新绑定当前文档。
- 关闭时保留已收到的部分回答；重开标为未完成，并提供显式重试。未完成回答不进入追问上下文，恢复不自动调用 AI。跨页面笔记本记忆仍默认关闭，与本页恢复独立。
- 网页工作区仅存于当前浏览器 IndexedDB：保留 30 天、最多 20 篇、总量 256 MB，超限清理较旧记录。单份快照最多 48 MB，图片仍受 40 张/32 MB 载入上限约束。API 配置不进入快照；保存失败保持可见且不阻断问答。“清除本页记录并关闭”只删除本页记录。
- 问答采用输入/回答分栏，小屏改为单列。图表参与范围、历史对话和设置可折叠；回答区提供复制、Markdown 导出、新对话，保留 Ctrl/Cmd+Enter 发送。使用同一解析浮窗和代码框恢复已完成的代码。

网页恢复适用于网页论文入口。PDF/Word/TXT/Markdown 文档阅读器共用问答错误隔离和界面改进，关闭文件后的完整文档会话仍不持久化。恢复功能无法找回升级前已经丢失的问答内容。

验证方法与范围见 [0.9.7 验证记录](VERIFICATION_0.9.7.md)。
