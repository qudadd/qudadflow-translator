# Store presentation 0.9.8

The paper research positioning and versioned 0.9.2 screenshots are retained. Current full descriptions:

- [English](store-description-en-0.9.8.txt)
- [简体中文](store-description-zh-0.9.8.txt)

The 0.9.8 descriptions add one HTTP/HTTPS website authorization, explicit continuation after webpage translation failures, silent restore, and the existing webpage-paper workspace recovery. Translation checkpoints are page-memory only; saved paper workspaces are a separate browser-local feature. No new manifest permission or runtime dependency is introduced.

See [release notes](RELEASE_NOTES_0.9.8.md), [reviewer guide](REVIEWER_GUIDE.md), [verification](VERIFICATION_0.9.8.md) and [observed submission status](STORE_SUBMISSION_0.9.8.md). Historical [0.9.5 presentation](STORE_PRESENTATION_0.9.5.md) and screenshot assets stay versioned.
