# QudadFlow Translator 0.9.2

- 连接程序改为按需引导：只有主动选择 ChatGPT 计划且未检测到可用连接程序时，才显示下载操作。兼容的已安装版本直接复用。
- 下载权限为可选权限，仅在“下载并继续授权”中请求，跟踪本次下载。下载中断时提供重试及手动下载，连接程序就绪前不会打开账号授权。
- 用户打开下载文件并确认安装后，返回设置页自动检测并继续官方授权。停止等待、切换方案或关闭设置页会停止自动继续。浏览器不会静默执行程序，安装器当前未签名。
- 弹窗不再等待系统平台检查或注入整套网页翻译脚本，只读取所选文字；网站权限和本地设置并行读取。
- 后台唤醒复用已持久注册的快捷键脚本，不再扫描、注入所有已打开标签页。
- 合并相同的在途翻译请求；MyMemory 相同片段可跨网页和文档请求复用。保留有界缓存，按接口、凭据、模型、语言与上下文隔离。连接测试和 ChatGPT 计划结果不使用译文缓存。
- 本地 Translator 模型短时复用，最多保留两个空闲实例，30 秒后释放。语言方向不可用不会拖累其他已准备好的语言；手动准备模型后立即清除该方向的不可用记录。
- 沉浸式翻译分发前复用同一轮的元素样式检查，减少深层 DOM 重复计算，继续按原文节点定位和当前视区优先派发。
- 修复 iframe 重载后残留原文节点被再次派发，以及 PDF 连续阅读中布局调整产生的滚动事件覆盖新阅读位置的问题。
- 本机连接保留 30 秒供连续请求复用；Windows 凭据保护使用编译入口，兼容旧 DPAPI 文件，且每次检查磁盘变化。另一浏览器的退出、令牌轮换、额度暂停仍生效。
- 扩展版本号及显示版本统一为 0.9.2。

性能数据、测试范围和复现方法见 [性能报告](PERFORMANCE_0.9.2.md)。ChatGPT 计划资格、安装要求和已知限制见 [登录说明](CHATGPT_LOGIN.md)。发布与审核状态见 [三平台记录](STORE_SUBMISSION_0.9.2.md)。
