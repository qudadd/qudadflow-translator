# QudadFlow Translator 0.9.1

发布日期：2026-10-29。0.9.0 的默认免 Key 机器翻译、沉浸式定位优化、设置合并及 ChatGPT 官方登录预览继续提供；本次更新改进 Windows x64 连接程序的安装流程。三平台实际进度见[发布记录](STORE_SUBMISSION_0.9.1.md)。

安装或更新商店版扩展后，Windows x64 用户首次打开弹窗时会看到可关闭的询问。仅在用户点击“同意并下载”后，扩展才打开 0.9.1 独立安装器的 GitHub 下载地址，并展示 ChatGPT 设置说明；当前机器翻译或自备 API 方案不会改变。用户仍须在浏览器下载列表打开 EXE。安装器先校验内置文件摘要，再自动解压并安装到当前 Windows 用户，注册 Edge 与 Chrome 正式扩展 ID；无需预装 Node.js 或管理员权限。侧载开发版会显示针对当前扩展 ID 的安装命令，不会下载不适用的商店安装器。发布页保留 ZIP 手动安装方式。

浏览器扩展无法执行下载的程序，Windows 也可能要求安全确认；当前 EXE 尚未签名。此流程不能实现“同意后静默安装”，不会绕过浏览器或 Windows 安全提示。默认机器翻译无需连接程序。ChatGPT 计划授权仍由用户在 OpenAI 官方页面完成；符合资格的 Plus／Pro 已见官方说明，Business／Team 成员经此路径使用自己额度的资格仍未获官方确认。

安装器的本地自检验证内置 ZIP 的文件摘要和解压路径；完整扩展回归、安装器负面测试与本版 ZIP 审计见[发布记录](STORE_SUBMISSION_0.9.1.md)。浏览器实际下载及 Windows 安全提示依用户设备和浏览器而异；本地自检不代表已在所有设备完成真实安装。
