# 0.9.6 论文作者名单排版优化

日期：2026-11-05（Asia/Shanghai）。本轮处理网页沉浸翻译中作者被拆为“一位作者占一行”的问题。0.9.6 仍为本地开发版，本轮构建位于 `outputs/dev-builds/release-v0.9.6-20261105-authors/`。

## 行为变化

以前每位作者都可能成为独立段落，作者列表的行内元素中插入块状译文，导致原名单和逐人译文交错、纵向堆叠。识别作者名单后，现在将整份可见名单作为一个翻译单元，在原名单下方显示一段自然换行的译文。横向作者信息栏有详情按钮等控件时，译文放在该信息栏下方，保持原名单的可用宽度。

- 原姓名、顺序、节点、链接和点击监听保留；单位上标、共同贡献及通讯作者符号、ORCID、邮件入口保持在原处，这些标记不混入姓名翻译请求。
- 单位、作者介绍与作者贡献正文继续独立分段翻译。作者姓名的 givenName / familyName 字段连成完整姓名，重名保留。
- 展开更多作者、隐藏、重排及移动名单后更新配对；名单改动使旧记录失效，恢复原文撤销译文且不残留旧位置的节点。
- 已为目标语言的姓名可跳过；按姓名判断混合名单，避免多数中文姓名掩盖少量外文作者。
- 长名单仍受请求长度限制，各片段合并为一个译文段落。提供方返回的逐人换行折叠为空格；原文原有的名单布局不改写。

识别常见 PubMed、Springer/Nature、Wiley 名单结构及 schema.org 作者元数据。Wiley 由模拟结构验证。无法识别的自定义署名区域继续按常规段落处理。本轮生产运行代码仅修改 `src/content.js`，权限、依赖与 PDF/图表实现没有新增改动。

公开页面快照来自 PubMed 42472916、Springer s40001-026-04947-z、Nature s41586-021-03819-2，分别在 320、768、1440 px 下回放，使用约 1.6 倍字符数的模拟中文检验文本增长。核对原名单标记、可见姓名的相对位置、尺寸和总行高；隐藏姓名的零面积矩形仅核对可见性，不按位置比较。PubMed 窄屏的自适应容器末尾空白宽度可减少约 4 px，实际姓名位置和行布局保持。

Springer 390 px 与 Nature 1280 px 另使用新隔离 Edge 访问真实公开页面，保留网站脚本与样式；原名单标记保持一致，名单内没有插入逐人译文。在线和快照检查都使用本地模拟翻译。本轮没有调用真实翻译服务评估姓名译名，不能据此评价人名译名的准确性。Chrome 检查使用内容脚本和模拟消息桥，完整扩展装载/后台由 Edge 检查。

## 基线与交付

从上一轮已验证的 0.9.6 运行包提取旧内容脚本，在隔离扩展中重现逐人堆叠。旧运行包及内容脚本的 SHA256 记录在 `before/provenance.json`；旧版预期失败不计入以上通过数。中途修复过程和诊断保留在本地输出中。较早的网页扩展验证记录保持原样，不与本轮检查重复相加。

可读报告、前后截图和最终原始 JSON 位于源码仓库外的 `outputs/dev-runs/author-layout-20261105/`。`summary.json` 保存报告、运行文件和构建资产的哈希。便携入口负责构建新目录与备份/同步本地侧载文件，运行包仍为 276 项，源码包另含本验证文档。重跑方式见[网页测试指南](IMMERSIVE_WEB_TESTING.md)。
