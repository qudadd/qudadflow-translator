QudadFlow Translator 是面向论文深度阅读与图表学习的研究工作台，将 PDF 对照翻译、正文与图表联合问答、图表精读和 Python/R 样式复刻集中在 Edge / Chrome 中。适合阅读外文文献、梳理研究方法、准备文献汇报和学习学术绘图。扩展操作界面为简体中文。

PDF 对照翻译：保留原文，连贯阅读论文
• 原版左右对照：同屏查看原文页与译文页，尽可能保持 PDF 页面比例、图片与图表位置，便于核对术语、公式附近的说明和上下文。
• 段落对照：将对应原文和译文配对阅读；沉浸原位：在原文字区查看译文，点击译文可回看原文。放不下的长译文保留完整译文入口。
• 支持逐页或连续阅读、当前页或全文翻译、停止与继续，以及双语 TXT 导出。也可打开 Word DOCX、TXT、Markdown 本地文件或已授权文档链接。

论文精读：把问题、正文与图表放在一起
从论文网页打开可移动、缩放的独立问答窗口，或直接使用文档阅读器中的研究工作台。结合提取的正文、图注和所选图表，可围绕研究目的、实验设计、分组与对照、方法与统计、结果解释、证据和局限持续追问。回答保留可用的页码、图号和来源线索，便于返回原文核对。

内置论文精读、方法/统计审查、图表解读三类 Skill 提示模板，也可编辑或导入自己的分析模板。支持多轮问答和 Markdown 导出；可选笔记本记忆默认关闭，开启后可按研究笔记本积累相关分析，并在设置中搜索、删除和导出。

网页论文重复打开同一文章，可恢复保存在当前浏览器的草稿、对话、图表和代码。长回答在可调整大小、可折叠的对话区内滚动；失败图片不阻断正文问答，断流保留已收到内容并提供显式重试。文档阅读器关闭后的完整会话暂不保存。

图表深度解读：学习图中如何表达研究证据
按编号和图注提取网页或 PDF 中的图表，搜索、全选并批量载入页面可提供的高清原图。PDF 支持本页或全文提取；遗漏时可框选、导入或粘贴截图，也可主动发起 AI 补充识别，核对候选后加入。

打开图表解析浮窗，原图与“解读 / Python / R”分页并排显示，可切换上一张、下一张或最大化。工作台还可展开为大视图，便于同时查看图表与长篇回答。结合视觉模型和论文上下文，可逐层学习：
• 图题、图注、坐标轴、单位、类别和图例各自代表什么。
• 多面板如何组织，颜色、线型、点形与分组如何对应。
• 趋势、组间差异、误差线或区间应如何结合方法解释；说明不足时保留不确定性。
• 当前图表如何支持正文结论，哪些只是可见现象，哪些需要额外数据或实验依据。

图表样式复刻：把视觉分析转为 Python / R 代码
在解读后生成绘图草稿，学习如何用代码表达原图的图层、面板布局、宽高比、线性或对数坐标、刻度形式、字体字号、配色、线型、点形、图例位置和顺序、标注与留白。重点是形式、风格和表达方式的复现，不要求还原论文的原始数值。

折线、散点、分组柱图及通用多面板可以共用一份图形规格生成 Python/R，切换语言复用规格。复杂混合图层、镶嵌图、断轴等特殊结构使用自定义代码草稿。独立代码框提供行号、一键复制、下载、自动换行和放大查看，运行说明、规格及数据模板可展开查看。

通用模板提供 --style-demo 演示模式，无需原始 CSV 即可在自己的 Python/R 环境试跑并导出 PNG、PDF、SVG，先查看布局、字体、配色、图例和标注。合成演示数据及图片会明确标记，不能用来支持论文结论。还可导入本地试运行图，主动点击“对照原图修订”，让所选模型对比原图与试运行图并提出视觉修订。扩展只生成代码和说明，不执行代码或安装依赖。

表格整理：从论文证据到可复制资料
原生文字表格可在本地复制或下载为 Markdown / TSV，便于整理到笔记或表格软件。图片表格可主动调用视觉 AI 转写，保留可见表头、单位、脚注和区间，对看不清或缺失的内容作出标记；转写结果需要对照原图核查。

基础阅读与模型选择
同时提供网页沉浸式双语阅读、按站点启用的划词翻译、可调译文颜色和快捷键。默认机器翻译无需 API Key：优先使用已准备好的浏览器本地模型，否则使用 MyMemory。MyMemory 会接收请求文字、可能保留内容，匿名通常每天 5,000 字符，共享网络可能共用额度；不是不限量服务。

一次确认所有 HTTP/HTTPS 网站权限，网页、原图、远程文档和 API 共用授权。缺失或撤销权限时显示授权入口，仅授权不会发送内容。网页翻译出错、断流或主动停止后，“继续翻译”保留已完成段落与分块，只重试未完成内容；进度仅存于当前网页内存，刷新或关闭后丢失。“恢复原文”直接关闭翻译面板，不弹出额外结果框。

深度问答、图表理解及代码生成需要兼容的 AI 服务，图片任务需要支持图像输入的模型。可配置自己的 OpenAI 兼容或自定义 JSON API；基础翻译还支持 Google Cloud Translation、DeepL、Microsoft Translator。最多保存 20 个本地方案，API 方案在设置中切换，阅读页可读取和选择当前服务的模型。

符合资格的用户也可选择 ChatGPT 计划登录预览，使用独立的 v0.9.2 Windows x64 连接程序。缺失时按引导下载，用户打开安装文件并确认一次后返回设置继续官方授权；可选下载权限只监测该文件，已有兼容程序直接复用。安装器目前未签名，另有 ZIP 手动方式。OAuth 凭据由本机程序保护，不读取 ChatGPT Cookie、不收集密码或自动切换到付费 API。官方开源接入目前只明确列出符合资格的 Plus/Pro，Business/Team 经此路径的资格尚未确认。默认机器翻译和自备 API 无需该程序。

使用范围与数据
文件和表格在浏览器本地解析；提取、选择、载入本身不发起 AI 分析。主动分析时，所选文字、图片和已启用的相关记忆直接发往所选服务商。密钥和设置保存在浏览器本地，网站/API 操作统一请求已有的可选 HTTP/HTTPS 网站权限；没有开发者翻译代理、广告或分析追踪。

自动提取与 AI 解读受页面结构、图片清晰度和模型能力影响。AI 分析、转写与代码需要核查；样式复刻不等同于科学结果验证。文件最大 25 MB，PDF/渲染后 Word 最多 300 页；扫描正文需要外部 OCR，暂不导出保持版式的译后 PDF/DOCX。服务商账号、费用、上下文及额度限制由所选服务决定。
