QudadFlow Translator 以沉浸式网页阅读、划词翻译为核心，并提供 PDF、Word DOCX、TXT、Markdown 文档阅读及可选 AI 论文研究工具。传统机器翻译与 AI 均可用于基础翻译。扩展界面为简体中文，名称统一为英文。

网页沉浸式与划词翻译
• 原文旁显示译文，保留普通链接和网页结构；当前视区优先，滚动、展开及动态文字继续补译。
• 自动跳过可信识别为目标语言的内容；按站点启用划词按钮，选中文字后点击翻译，单纯划选不会发出请求。
• 可自定义沉浸式译文颜色，提供浅色/深色预览；默认 Shift+A，可手动输入或录制其他组合并保存，也可恢复或停用。输入框与编辑器保留正常操作。

自备 API 与模型选型
支持 Google Cloud Translation、DeepL、Microsoft Translator、OpenAI 兼容 Chat Completions/Responses 和自定义 JSON 接口。最多保存 20 个本地方案，可从弹窗切换。支持读取上游模型、搜索和查看服务商声明的能力，由用户明确选择；没有元数据时标记为未知。可先测试草稿，再保存应用。

翻译与 AI 请求不设扩展固定超时，遇真实 HTTP/网络/流错误或手动停止时结束；服务商限制仍适用，文件和图片下载保留资源保护。MyMemory 仅提供有限免 Key 基础试用，匿名通常约 5,000 字符/天，并非不限量接口。

文档原位与左右对照
本地打开文件或已授权的文档链接，选择沉浸原位、原版左右对照或段落对照。PDF 保持页面比例及图表位置，无法容纳的长译文提供完整译文入口。支持翻译当前页/全文、停止/继续及双语 TXT 导出。Word 呈现可能与 Microsoft Word 不同。文件最大 25 MB，PDF/渲染后的 Word 最多 300 页；扫描正文替换需外部 OCR，暂不导出保持版式的译后 PDF/DOCX。

论文问答、图表提取与可复制表格
网页可打开可移动、缩放的独立论文问答窗；文档阅读器共享研究工作流。提取的正文不设固定字数截断，仍受模型上下文、请求大小和浏览器内存限制。利用编号、图注和结构识别图、图片表格及原生/ARIA 表格；支持图表全选、搜索、批量载入可用高清原图，再结合所选证据提问。原生表格可本地复制 Markdown/TSV，图片表格须明确点击视觉 AI 转录并核对。漏提取时可导入/粘贴图表截图，或补入原文当前视区。捕获、选择、载入本身不调用 AI。

可选 AI 能解释图表并生成可下载的 Python/R 复现草稿，扩展不执行代码。支持可编辑 Skill 提示模板和默认关闭、可导出的跨页面笔记本记忆。自动提取为启发式识别，无法保证所有出版商与表格均成功，AI 数值、结论和代码需独立核查。

数据与权限
文件在浏览器本地解析，主动翻译时仅将所需文字或所选图片直接发送至配置的服务商；没有开发者翻译代理、广告或分析追踪。密钥和设置保存在当前浏览器。网站/API 权限按需申请，也可主动一次授权所有网站以减少提示。浏览器内部页及内置 PDF 页请使用扩展的独立阅读入口。
