Your colors. Your reading shortcut.

Choose immersive text colors with light/dark previews. The webpage shortcut defaults to Shift+A: type another combination and save, or record it. Reset or disable it at any time. Inputs and editors keep normal typing. These preferences apply without retranslating or changing API profiles.

Read the content in front of you.

Immersive translation prioritizes the live viewport and supplements scrolling, expanded and dynamically changed text. Confidently detected target-language text is skipped. Use the nearby opt-in selection button for a passage. Browser-internal pages and built-in PDF viewers use the separate extension entry points.

Keep the page. Translate in place.

Open PDF, Word DOCX, TXT or Markdown locally or from a permitted URL. Choose in-place immersion, original-layout comparison or paired paragraphs. PDF page proportions, images and charts stay in position; long or unsupported text has a full-translation fallback. Translate the current page or all pages and export bilingual TXT.

Files are limited to 25 MB; PDF/rendered Word retain a 300-page bound. Extracted body text and TXT/Markdown have no fixed character cutoff, but provider context and browser memory limits remain. Word layouts can differ from Microsoft Word. Scanned body replacement needs external OCR. Layout-preserving PDF/DOCX export is not included.

Ask about papers and their evidence.

Use a movable, resizable paper Q&A window or the document research workflow. Caption/number-aware extraction inventories figures, image tables and native/ARIA tables. Search or select all figures, batch-load available high-resolution originals, and combine selected figures with the paper text. Native tables copy locally as Markdown or TSV. Image tables require explicit vision-AI transcription and checking. For missing material, import/paste a screenshot or add the source viewport.

Capture, selection and loading do not call AI. Optional analysis explains figures and creates downloadable Python/R drafts; code is never executed. Editable Skill prompts and project-isolated cross-page notebook memory are available; memory is off by default and exportable in Settings. Automatic extraction is heuristic and cannot guarantee every website. Up to four original images can accompany a paper question; loading/capture resource bounds remain.

Your provider. An informed model choice.

Save up to 20 API profiles for Google, DeepL, Microsoft, OpenAI-compatible or custom JSON services. Fold settings sections individually. Read upstream models, search reported capabilities, explicitly choose and test a draft before saving. Missing metadata stays unknown. MyMemory offers a limited key-free trial, typically 5,000 anonymous characters/day; it is not unlimited and may retain submitted text.

Translation, model discovery, tests and AI analysis have no extension deadline. Actual HTTP/network/stream errors or Stop end a call; provider limits still apply. Separate document/image downloads retain safeguards. Site/API access is requested as needed; an explicit optional all-websites grant reduces prompts.
