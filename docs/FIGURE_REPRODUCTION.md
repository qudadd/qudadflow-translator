# Python / R 图表样式复刻

目标是用可运行代码复现原图的形式、风格、图例、字体、布局和标注。验收不要求数值还原，不以重新计算统计量或数值相似度作为通过条件。

## 从原图到试跑

1. 提取或导入图表，在总览点击“打开解析浮窗”。宽屏左侧看原图、右侧看当前结果；小屏纵向排列。解读、Python、R 分页显示，关闭浮窗保留结果及正在接收的内容。
2. 完成图表解读后生成 Python 或 R。先清点全部图层，包括背景轨迹、汇总线、参考线、分面标题条、图例符号和顺序、注释框、面板字母。缺少原始数据时仍应复现这些视觉层次。
3. 独立代码框提供行号、一键复制、下载、自动换行和放大查看。复制失败时自动选中代码供 Ctrl/Cmd+C。放大视图按 Esc 返回；运行说明、JSON 规格和数据模板折叠显示。
4. 折线、散点、分组柱图和最多六个通用面板使用同一 JSON 规格生成两种语言，切换语言不重新请求模型。下载脚本后可直接用演示模式试跑，无需 CSV：

   ```text
   python QudadFlow-figure.py --style-demo
   Rscript QudadFlow-figure.R --style-demo
   ```

5. 查看 `figure-style-demo.png`、`.pdf`、`.svg`。演示模式使用两种语言共享的确定性合成值，图片标注 STYLE DEMO；这些值用于展示样式，不代表论文观测或统计结论。每个面板独立生成演示值，避免不同数据筛选互相干扰。
6. 点击“导入试运行图”本地载入图片，再点击“对照原图修订”，才发送原图、渲染图和规格给所选 AI。对照依次检查结构与图层、轴和刻度形式、字体、颜色、线型、图例、标注和留白，不检查数值还原。

## 运行与支持范围

Python 依赖 pandas、numpy、matplotlib；R 依赖 ggplot2、jsonlite、svglite。扩展仅生成代码和说明，不执行代码、不安装依赖。两种语言的字体和排版引擎会有差异。

通用规格支持线性／对数轴、显式刻度与范围、类别顺序、颜色、字体、尺寸、图例位置及区间端点。镶嵌图、断轴、热图、混合图层、灰色个体背景叠加彩色汇总线、特殊图例、复杂标注、纹理等应标记 custom，提供完整自定义代码；不得为套模板丢失这些结构。自定义代码也应实现带明确标记的 `--style-demo` 运行路径，具体依赖和限制由说明列出。

同名输出存在时，模板停止并保留原文件；请将上轮结果移入其他目录后重跑。演示图和正式数据图使用不同文件名。若一个面板复用同一列承担互相冲突的字段角色，演示模式提示需要独立列；正常 CSV 路径仍保留。

## 可选：替换为自己的数据

将规格指定的 CSV 与脚本放在同一目录，不加 `--style-demo` 即可用自己的数据运行。下载的空模板只有表头。数据来源、估读和缺失状态分别保留；正式数据路径仍检查列名、有限数值、分组与区间端点，防止运行错误。SD／SE／CI／range 的含义不能在视觉修订时改写。

正式数据输出 `figure.png`、`.pdf`、`.svg` 和 `render-audit.json`；演示记录使用 `style-demo-audit.json`，明确标记 synthetic。它们是运行记录，均不提供图像相似度分数，也不是本次形式与风格验收的数值评分。

## 本地检查与示例

```powershell
node tools/figure-spec-check.mjs
node tools/figure-style-examples.mjs NEW_EXAMPLE_DIRECTORY
node tools/figure-compile.mjs figure-spec.json NEW_SCRIPT_DIRECTORY
```

样式示例实际运行 Python/R 的折线、柱图与双面板脚本；在没有 CSV 的情况下检查正常退出、三种导出、可编辑 SVG 文字、图例与演示标记。输出 `index.html` 可并排看图。这验证本地代码与模板，不代表真实视觉模型对任意论文的识别质量。

便携开发包 `development/Run-Checks.ps1 -Suite quick` 包含规格检查；`-Suite all` 包含隔离 Edge 中的浮窗、复制、代码放大、语言切换、规格下载、原图修订及取消流程。浏览器检查使用本地模拟服务，不访问用户账号。

旧 `tools/figure-examples.mjs` 保留为使用 R ToothGrowth 数据的正式数据运行回归，可选运行。它的数值核对不属于样式复刻验收要求。
