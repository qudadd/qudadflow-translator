QudadFlow Translator 保留网页原文，在附近显示译文；也支持 PDF、Word DOCX、TXT、Markdown 阅读，以及可选的论文问答、图表分析和可复制表格。扩展界面为简体中文。

0.9.0 更新
未配置 AI 账号或 API Key 时，默认即可使用机器翻译：先尝试已准备好的浏览器本地 Translator 模型，否则立即使用 MyMemory 公共服务。浏览器支持时，用户可在设置中点击按钮下载相应语言方向的本地模型。MyMemory 会接收主动请求的文字，可能长期保留，且受服务商额度限制：匿名通常每天 5000 字符，共享网络可能共用计数。可自愿填写自己的联系邮箱使用服务商说明的较高额度，或配置自己的翻译服务；不承诺 MyMemory 为每位用户提供完全独立的额度。

长段落按小片段拆分，在限定并发下处理并按原文顺序显示；成功的重复片段可复用短期内存缓存。沉浸式译文更贴近链接文字，并适配竖排书写方向。实际速度和排版效果因网页、浏览器和服务商而异。

已保存方案、接口选择、上游模型、连接测试和保存设置集中在一个分区。读取模型不发送网页正文；需要用户在列表中明确选择并填入，适用于自备 API 和可选的 ChatGPT 计划预览。

可选 ChatGPT 计划登录预览
符合资格的用户可主动选择官方 Sign in with ChatGPT。该功能需从 v0.9.0 GitHub Release 单独下载 Windows x64 本地连接程序，解压后由用户安装；浏览器不会代为安装。本机程序使用 Windows DPAPI 保护 OAuth 凭据，仅将主动请求的文字和图片直接发送到 OpenAI 官方 Responses API。扩展不读取 ChatGPT Cookie、不收集密码，也不会自动转到付费 API。每位用户以自己的账号授权。OpenAI 开源计划额度文档目前只明确列出符合资格的 Plus／Pro；Business／Team 经此路径的资格尚未确认，组织也可能拒绝授权。默认机器翻译和自备 API 无需本机程序。更新后首次打开扩展时会显示一次可关闭的安装引导。

网页、文档与论文
沉浸式翻译优先处理视区内容，随滚动和动态变化补充。按站点启用划词按钮后，选中再点击才发送文字；默认网页快捷键 Shift+A 可修改。阅读器提供原位、原版对照和段落对照，PDF 可逐页或连续阅读并导出双语 TXT。尽可能保留 PDF 页面比例；扫描正文需要外部 OCR，暂不导出保持版式的译后 PDF／DOCX。

按图注提取网页与 PDF 图表、原生文字表格和受支持的图片表格。原生表格可本地复制 Markdown／TSV；图片表格转录、PDF AI 补充识别和论文问答需用户主动选择兼容 AI 模型并发起请求。工作台可展开显示大图和独立问答栏。Python／R 复现草稿仅下载为文字，扩展不会执行；AI 结果仍需核对。

数据与权限
文件和表格在本地解析。主动请求的文字及所选图片直接发往所选服务商；MyMemory 只在默认机器翻译模式下作为回退。设置和 API Key 存于浏览器本地，ChatGPT OAuth 令牌留在单独安装的本机程序。nativeMessaging 权限只用于连接该程序。网站和自定义 API 域名按需授权。没有开发者翻译代理、广告、遥测或远程执行的扩展代码。
