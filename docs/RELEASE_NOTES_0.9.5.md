# QudadFlow Translator 0.9.5

本版统一中英文产品介绍，突出论文深度阅读与图表学习：PDF 对照翻译、正文与图表联合问答、方法与统计讨论、图表精读、可复制表格，以及 Python/R 样式代码、演示试跑和原图视觉修订。

安装包中的本地化摘要随版本更新为 0.9.5，确保 Chrome、Edge 与 GitHub 的简介定位一致。README 和项目网站首屏以论文研究流程为主，沉浸式网页与划词翻译作为基础能力。研究及翻译功能代码、权限和依赖沿用 0.9.4；Windows 连接程序继续使用独立的 0.9.2 版本。
