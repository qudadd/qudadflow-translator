QudadFlow Translator 隐私政策

版本 0.8.7 · 生效日期：2026 年 10 月 22 日

本政策说明 Microsoft Edge / Google Chrome 扩展 QudadFlow Translator 如何处理信息。开发者支持与隐私联系邮箱：lcf1249288484@outlook.com。

处理的信息

你主动发起翻译后，扩展读取选中文本或当前网页中的可见文本，并将其与源语言、目标语言以及所选 API 必需的鉴权和配置字段直接发送至你配置的端点。根据接口类型，请求还可能包括模型名称、翻译指令、段落标记、自定义字段或请求头。

扩展不收集浏览历史，也不会未经操作发起翻译。主动开启沉浸式翻译后，会扫描页面正文、开放 Shadow DOM 及可访问的同源框架，并在阅读时补译新显示、插入或修改的内容。文字脚本判断和浏览器本地语言识别用于跳过确认已是目标语言的文字，不调用额外的远程语言识别服务。关闭浮窗、恢复原文、更改翻译配置或跳转页面时停止补译。网页提取会跳过编辑区域、隐藏内容、已插入的译文及标记为排除的内容。你明确选中的文字仍可能在划词翻译时发送。

文档阅读器

0.7.0 的文档阅读器支持 PDF、DOCX、TXT 和 Markdown。你选择或拖入的文件由随包提供的库在浏览器内解析。打开远程文档链接时，扩展请求来源站点的 HTTP(S) 协议和主机（所有端口）访问权限，再将文件下载到浏览器。浏览器规则允许时，下载可能携带该来源站点的登录 Cookie；不会将翻译 API Key 附加到文档下载请求。本地选择文件不需要开放所有 file-URL 的访问权限。

打开文件或翻页本身不会发起翻译。点击翻译后，扩展仅向所配置 API 发送提取文字及翻译配置，不向它上传原始 PDF/DOCX 文件或 PDF 密码；嵌入图片只有通过下述可选 AI 工作流才会发送。来源链接保留在阅读器的临时输入框中，不作为翻译上下文发送。加密 PDF 如需密码，仅用于本地解密。文档中的 JavaScript 和外部资源不会执行或加载。

文件数据、提取文字及译文暂存于打开的阅读器标签页内存，关闭或替换文档后清除该阅读状态。成功的文字翻译也可能留在下文说明的有限工作线程内存缓存中。扩展不保存原始文档库或正文翻译历史；可选研究记忆另见下文。主动导出双语 TXT 时，浏览器会把文件保存到你选择的下载位置；需要删除时请在该位置操作。

可选的 AI 图文工作流（0.7.0）

传统机器翻译和 AI 都能翻译正文。最下方独立工作流可提取 PDF 位图区域或 Word 图片，也可框选 PDF 区域或提取整页。提取与预览在本地进行，不调用 API。只有点击分析按钮后，才将所选图片、目标语言、分析指令、模型及鉴权字段直接发送到当前或单独选定的已保存 OpenAI 兼容 AI 端点。整页提取会包含该页所有可见内容的图片；不发送原始文档文件或密码。

文档提取图片、预览及 AI 结果保留在阅读器标签页内存；主动开启研究记忆后可另存分析文本，不进入服务工作线程的文字缓存。关闭或替换文档会清除它们，更改配置会清除分析结果。下载的图片和导出的双语 TXT 保留在所选下载目录。AI 服务商适用自己的数据保留条款；请选择合适的区域和可信端点，并对照原图核对文字及图表解释。

论文问答、Skill 与可选跨页面记忆（0.8.7）

论文入口会打开独立浏览器窗口，显示本地提取的正文、表格、图表候选和来源。切换到另一篇论文后可再次主动提取，已有窗口保留其原来来源，不会后台抓取、自动读取补充附件或自动同步旧窗口。全文分析不按固定正文字数截断，而是发送完整提取材料；上游服务的限制仍然适用。

论文图表总览默认依据图注、引用及图表语义保留图表，排除普通网页配图和自动整视区图，仍可主动手动补图。搜索和选择保存在当前窗口内存中。原图未载入时，可显示本地捕获的缩略预览，否则使用占位信息；预览与可用于分析的原图区分。全选包含筛选外及原图待载入的可用图表，取消全选清除共享勾选；原生文字表格无需勾选即进入论文材料。勾选不下载原图，也不调用 AI。明确点击批量载入全部、筛选结果或所选原图后，才合并请求相应来源权限并下载图片；明确点击批量解读后，才逐张向所选 AI 发送图片。论文问答每次最多发送四张所选原图。搜索不会取消筛选外的选择，总览会显示其数量。关闭或重新加载窗口会清空选择。

网页和 Word 原生表格、TXT / Markdown 管道表格在本地提取为可复制文字，无需 AI。点击复制会将所选表格写入系统剪贴板；访问失败时提供选中的只读文本供手动复制。Markdown / TSV 下载将表格内容保存在所选下载目录，需在该位置删除。明确点击图片表格转写时，会通过下述 AI 工作流发送所选图片及相关材料，结果未经核验，开启笔记本记忆后也可能保留分析文本。复制或下载已有表格不发起新的 API 请求。

论文问答可将明确勾选的最多 4 张原图、图注和来源标签与论文材料一起发送到所选 AI。单独载入图片不调用 AI。本窗口最多保留 20 轮对话，追问请求附带最近最多 6 轮完整回答、合计 24000 字符；未完成回答可导出，但不参与后续上下文。除非开启笔记本保存或导出 Markdown，对话保留于窗口内存；关闭或刷新窗口会清除此对话，下面说明的独立提取缓存可能仍保留。

点击网页论文入口后，扩展在本地提取正文、表格、图注和图表候选。常规入口可临时截取活动视区，仅保留可见图表的裁剪区域。论文窗口内的补图步骤将整张原文当前视区截图加入同一窗口预览，其中可能包含界面或个人内容。图表编号核对在本地执行，不会自动调用 AI。网页和文档研究界面也支持主动导入或粘贴 PNG/JPEG/WebP 截图，导入图片仅保留于该窗口内存。截图、导入、粘贴均不调用 AI，也不会自动勾选图片；只有点击图片分析，或勾选后发起论文问答，才发送相应图片到所选 AI 端点。请核对预览、裁去不需要的内容后再分析。未显示的远程图片需单独点击加载并授权来源域名，下载不携带 Cookie、不跟随重定向；图片来源 URL 可暂存在提取缓存以支持加载。

网页提取缓存在本地 IndexedDB，最多 4 份，每份图片字节上限 16 MB（含最多 12 张补充截图），补图不延长原有 1 小时有效期。缓存还临时记录浏览器标签页/窗口/文档绑定、页面标题及 URL 摘要，用于防止不同论文截图混入；绑定仅在本地使用，不发送给 AI，绑定中不保存原始 URL 查询参数。到期后在后续研究管理/提取操作中清理，不运行后台定时删除。关闭研究标签页不会立即清空该缓存。本地文档图片仍只在标签页内存；卸载扩展删除该本地数据库。

论文、图表和代码生成会向所选 AI 发送选定材料、图注、相关页面文字、来源标题/页码及 HTTP(S) 域名和路径（去除查询参数、片段和凭据）、Skill 指令、可选问题和启用的笔记本上下文。文件名可能作为标题发送。不上传原始文档或密码。基础正文翻译不附加来源 URL 或研究记忆；服务商适用自己的保留及计费条款。

Skill 是保存在本地的文本指令模板，不执行脚本。研究记忆默认关闭；主动开启后，完成的分析、有限原文摘录与来源信息在 IndexedDB 分条保存，并按笔记本隔离。每次启用记忆的分析仅选取该笔记本最多 6 条记录，上限 4000/6000（默认）/12000 字。基础翻译不创建或使用研究记忆；数据不自动同步至开发者、GitHub 或其他设备。

记忆总量最多 300 条、200 万内容字符，单条最多 2000 字原文摘录及 10000 字分析；内容去重，超限淘汰最早记录。期限可选 7/30/90 天（默认 90）或仅容量限制，到期立即排除出上下文，在后续研究管理操作删除。关闭记忆停止后续使用和保存，但不删除旧记录。设置支持搜索、删除记录/笔记本、清空笔记本及全部导出 JSON/Markdown。导出包含保存的研究文本、来源和 Skill，不含扩展 API 配置或图片字节；用户自己放进材料或 Skill 的个人信息仍属于该内容。

Python/R 功能生成文本草稿并提供下载，不自动执行代码。脚本、说明、图片和导出文件保留在下载目录，需要自行删除和核验。

翻译服务商

QudadFlow Translator 不运营翻译服务器或代理。你自行选择 Google Cloud Translation、DeepL、Microsoft Translator、OpenAI 兼容服务或自定义 JSON 服务及其端点。该服务商接收翻译请求，并适用其自己的隐私、数据保留、安全和计费条款。请选择可信端点，远程服务请使用 HTTPS。

服务商隐私信息：Google、DeepL、Microsoft。其他端点请查阅相应服务商的政策。

可选的上游模型读取和草稿测试（0.7.1）

点击“读取上游模型”后，当前草稿的 API Key 和自定义请求头直接发送到 OpenAI 兼容端点同源的模型地址（通常 /v1/models），不附带网页正文、文档、研究记忆或图片。请求不携带 Cookie、不跟随重定向，响应最多 2 MB、最多 1000 个去重模型。返回的模型 ID 和能力元数据仅保留在当前设置标签页内存，不保存为配置历史。

你明确点击后才把模型 ID 填入草稿，缺失能力显示未知。“测试连接”将固定短句“This is a connection test.”及当前草稿配置发送到翻译端点，绕过缓存，不保存或启用草稿，也不验证图片输入。读取及测试可请求持久的 API 域名可选权限；取消或未保存离开不会撤销该权限，可在浏览器扩展设置中撤销。

基础翻译、模型读取、连接测试及 AI 分析均不设扩展倒计时，持续等待完成、实际 HTTP／网络／流错误或手动取消。关闭或离开设置标签页会取消其待处理的模型读取和测试。上游与浏览器网络限制仍可能中断调用；图片和文档下载继续保留资源保护。

本地存储与 API 密钥

沉浸式译文颜色及网页快捷键作为浏览器本地偏好保存，独立于 API 配置方案，不发送给服务商或开发者。修改它们不会重新翻译、取消当前翻译或清除内存译文缓存。默认 Shift+A 仅在已授权 HTTP/HTTPS 网页正文触发沉浸式翻译，输入框和编辑器保留全选；设置中可手动输入并保存、录制、恢复或停用。

设置分区的折叠偏好通过 localStorage 保存在当前浏览器，仅包含分区标识及展开/收起状态，不包含论文或凭据。

最多可以保存 20 个具名配置方案，包括各自的 Key、端点、请求头和偏好，均保存在浏览器扩展本地存储中。首次使用时会保留原有已配置连接。选中方案进行编辑后，需要保存才会应用；弹窗也可直接切换已保存方案。删除当前方案同时清空其活动连接，其他方案继续保留各自凭据。方案不会同步到 GitHub 或发送给开发者；这是配置历史，不是翻译内容历史。

API Key、端点、模型、语言偏好及自定义 API 设置保存在浏览器的扩展本地存储中。扩展不会同步这些信息，也不会将其发送给开发者。API Key 和自定义鉴权字段会发送到你配置的端点，以验证请求。设置页切换服务商时会保留独立的临时配置草稿，不会自动复用另一服务商的 Key。

基础翻译译文显示在当前页面中，不会保存到扩展存储；研究分析另按可选记忆设置处理。沉浸式译文插入网页后，网页自身的脚本可能读取这些译文。恢复原文或刷新网页可移除插入的译文。

为加快重复阅读，服务工作线程可能在内存中暂存成功的原文和译文，复用有效期为五分钟，最多 128 条、合计 250000 个字符。过期条目在下一次缓存查询时移除。缓存不会写入磁盘，修改翻译配置后会清空（颜色与快捷键偏好保留缓存）；浏览器停止工作线程时也可能提前消失。连接测试绕过缓存。扩展不会维护持久的翻译历史。

可选的 MyMemory 免 Key 试用

你明确启用 MyMemory 基础试用后，提取文字通过 HTTPS 查询参数发送至 api.mymemory.translated.net，不携带 API Key 或来源站点 Cookie。需手动选择源语言。服务提供翻译记忆匹配与机器翻译，匿名额度通常为每天 5000 字符；其条款说明会长期保留提交的片段，并可能由第三方机器翻译服务处理。请使用非私密短文体验，并阅读其条款及隐私政策和额度说明。扩展只调用 GET 翻译接口，不调用贡献/上传接口，也不会暗中切换你的服务商。不承诺完全不限量的免费服务。

权限用途

设置中可主动点击“一次授权所有网站”，经浏览器确认后持久授予 HTTP/HTTPS 网站访问权限，减少网页、原图及 API 的后续确认。这允许扩展访问这些站点，但不自动为所有站点启用划词按钮，也不在没有翻译／分析操作时发送内容。“恢复按站点授权”会清除可选网站授权，包括已有的单独网站和 API 域名，之后按需重新请求。浏览器内置页和商店页仍受限制，本地文件 URL 访问需在浏览器扩展详情单独开启。

activeTab 和 scripting 用于在扩展操作后访问当前页并注入随包提供的翻译界面；storage 在本地保存 API 设置和偏好；contextMenus 提供右键翻译命令；可选主机权限允许向你配置的 HTTP(S) API 域名发送请求。如果你为某个站点开启划词按钮，Edge 会为该站点的 HTTP(S) 协议和主机（所有端口）注册随包提供的内容脚本。脚本只在选中文字后显示按钮，单纯选择文字不会发送请求。关闭开关会停止已打开页面中的按钮，并取消后续自动加载；Edge 会保留已授予的权限，直到你在扩展设置中撤销。

扩展仅在已授予访问权限的 HTTP/HTTPS 来源注册随包提供的轻量按键监听器，浏览器允许时也注入已有页面。它检查已设置的真实组合键及编辑区域焦点，不提取页面正文、不记录按键。主动触发翻译后才载入完整阅读界面。撤销网站权限会停用快捷键动作并更新脚本注册。浏览器保留组合键及内部页仍受浏览器规则限制。

广告、分析与远程代码

扩展不包含广告、跟踪、分析或遥测，开发者不出售个人信息。所有扩展可执行代码均随安装包提供；API 响应仅作为文本数据处理，不会作为代码执行。

你的选择与删除

你可以在设置页修改端点和凭据、通过 Edge 扩展设置撤销站点权限、恢复网页原文或移除扩展。移除扩展会删除它的本地扩展存储。这些操作不会删除 API 服务商已经保留的数据；有关删除及其他隐私请求，请联系该服务商。
