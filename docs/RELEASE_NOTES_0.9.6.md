# QudadFlow Translator 0.9.6

网页沉浸翻译与论文作者名单排版改进，2026-11-05。GitHub 发布及两家商店的实际状态见[发布记录](STORE_SUBMISSION_0.9.6.md)。

- 识别原生表格的 `caption`，让表格标题与单元格、图注一样参与翻译。
- 长段落优先在中英文句末切分，找不到足够长的完整句子时优先按词间空白切分。仍限制每段请求长度，并避免拆开 Unicode 代理对，减少上下文截断和字符损坏。
- 整页与沉浸翻译跳过代码、键盘键名、程序输出、MathML、KaTeX、MathJax，以及常见 Monaco/CodeMirror 编辑器与交互控件。原文保持原样，行内代码与公式也保留在原文中；译文不会重建公式或保证术语正确。
- 跳过 inert、aria-hidden 内容，状态改变后自动重新检查，避免翻译不应显示的背景内容。
- 按完整原文段落重新核对文本节点、顺序和所属容器。动态评论换文、插入短语、重排节点或跨卡片移动后，移除旧译文并重新配对；未变化的段落继续复用。
- 保持 flex/grid 原文节点的身份及包装恢复，开放 Shadow DOM 和可读同源 iframe 继续参与；不增加站点权限。
- 翻译完成后，状态浮窗自动收为显示段落数的小条。点击 `+` 展开状态、`−` 收起，恢复原文入口保持可用；手动展开不被后续补译收起，错误会展开显示。
- 扩展测试后补充裁切布局适配：多行省略或固定高度容器挡住译文时临时放开高度和行数上限，保留横向裁切及原有滚动容器；恢复原文时撤销标记，保留网站期间自行修改的样式。译文所属元素可在 flex/grid 中收缩，减少加长译文造成的横向溢出。
- Ruby 注音 `rt/rp` 保持原样，正文仍按完整句子配对。失效段落的旧请求无法重新插回译文，外部删除已完成译文后可自动补回。
- 固定/吸附定位的语义导航及含导航的页头保留原布局，避免 NumPy 等固定高度菜单被译文挤出可见区域；文档流中的导航与普通文章标题继续参与。保护视觉裁切的屏幕阅读器标签，按需限制被译文撑宽的 flex/grid 祖先，修复 BBC 窄屏页脚溢出。
- 默认机器翻译在同一批段落包含多种语言时分别检测源语言，保持段落标记、进度顺序、取消与缓存；每个请求内依次处理不同语言，避免放大页面原有的两个请求并发上限。同语言批次保持一次提供方操作，手动源语言继续优先。兼容浏览器返回的 `iw/in/ji` 旧语言代码。
- 识别论文作者名单，将整份可见名单配为一段译文，放在名单或横向作者信息栏下方，避免每位作者被块状译文拆成一行。原姓名、链接、单位上标、共同/通讯作者符号、ORCID 和联系入口保留；单位说明及作者贡献正文继续分段翻译。处理名单展开、重排、移动、中英文混合及长名单切分，并合并提供方返回的逐人换行。详见[作者排版验证](VERIFICATION_0.9.6_AUTHORS.md)。

新增可重复的网页回归入口与显式启用的真实默认服务抽测。测试方法、证据范围及服务术语限制见[网页测试指南](IMMERSIVE_WEB_TESTING.md)和[验证记录](VERIFICATION_0.9.6.md)。

第二轮进一步扩大网站、语言、视口、长文压力及在线页面覆盖，详见[扩展测试记录](VERIFICATION_0.9.6_EXPANDED.md)。Chrome 的内容脚本 DOM 检查与 Edge 的完整 MV3 集成结果分别记录，不把 Chrome 受测环境无法加载扩展计为通过。

权限、第三方运行依赖、PDF/图表工作流和独立 Windows 连接程序版本保持不变。
