QudadFlow Translator 0.9.0 defaults to key-free machine translation. For basic review: keep 自动机器翻译 in Settings, grant a normal HTTP(S) test page, then request immersive or selection translation. A ready on-device Translator model runs in an offscreen extension window; only language-pair availability is cached in its localStorage. A user-click in Settings can start a first model download. Otherwise requested text immediately goes to MyMemory via HTTPS, subject to its quotas and retention. No developer account or paid API is needed.

nativeMessaging supports only the optional ChatGPT plan preview. The browser cannot install a host. Selecting that plan without the host shows a guide to the separate Windows x64 companion in the v0.9.0 GitHub release; the user extracts and installs it. The one-time popup offer is dismissible and does not activate the plan. No reviewer account is supplied; users authorize at auth.openai.com. Tokens stay encrypted with Windows DPAPI in the companion; the extension stores an account reference and model. Requests use official Responses API with store:false and stream:true, without ChatGPT cookies or automatic paid API fallback. OpenAI explicitly lists eligible Plus/Pro for this open-source route; Business/Team access remains unconfirmed.

Saved profiles, provider, model, connection test and Save settings share one section. Model selection is manual. Immersive placement near links and vertical text is improved; PDF/Word/TXT/Markdown and paper tools remain. See https://github.com/qudadd/qudadflow-translator/blob/main/docs/REVIEWER_GUIDE.md . Checks use isolated browsers and synthetic providers; speed and account eligibility are not guaranteed. No shared credentials, remote extension code, ads or telemetry.
