# QudadFlow Translator 0.9.0

发布日期：2026-10-29。此版本的商店提交、审核和公开上架进度分别记录在 [三平台发布记录](STORE_SUBMISSION_0.9.0.md)。

## 翻译与设置

- 无 AI 配置时默认使用免 Key 机器翻译：优先尝试已准备好的浏览器本地 Translator 模型，否则立即使用 MyMemory。首次下载本地模型需要用户在同一设置分区点击“下载并准备本地模型”；浏览器不支持时该按钮停用。后台 Worker 不调用本地模型，翻译在扩展隐藏页面完成；仅在该页面的 localStorage 缓存语言方向可用性，不保存翻译文字。MyMemory 受服务商额度和保留条款限制，匿名用量可能按共享网络计数，不承诺每位用户独享。可自愿填写联系邮箱使用服务商公布的较高额度，或配置自己的服务商密钥。
- MyMemory 请求按段落及 500 UTF-8 字节切分，单任务最多并行 3 个片段、全部任务最多并行 4 个请求；译文仍按原顺序展示。短期内重复成功片段复用内存缓存。速度取决于浏览器模型、网络和服务商，本版未给出真实站点的通用加速比例。
- 沉浸式译文定位改进链接节点附近的插入位置，并继承竖排书写方向；保留原文与链接。布局不保证适配所有网页，遇到错位可恢复原文。
- “已保存方案”、接口类型、上游模型、连接测试和保存设置集中在“API 方案与模型”分区。账号模式与自备 API 均可从上游模型列表手动选择并填入；不会擅自替用户选模型。

## ChatGPT 官方登录预览

- 用户主动选择后，通过本机 Native Messaging 程序按 OpenAI 官方 Sign in with ChatGPT 开源流程授权。用户各自授权；令牌留在 Windows DPAPI 加密文件中，扩展只保存账号引用和模型。推理请求使用官方 Responses API，`store:false`、`stream:true`，必须收到 `response.completed` 才判定成功。不会读取 ChatGPT 网页 Cookie 或自动转到付费 API Key。
- Windows x64 用户可从本版 GitHub Release 下载独立连接程序 ZIP，解压后双击安装。它自带经过 Node.js 官方 SHA256 校验的运行时，按当前用户注册 Edge 和 Chrome 商店版 ID，无需预装 Node.js 或管理员权限。商店扩展本身无法静默安装本机程序；升级后首次打开弹窗只提供一次可关闭的安装引导，默认机器翻译不依赖此程序。此连接程序尚未签名。
- 个人 Pro 账号已在本地真实读取 8 个模型，并完成一次固定短句推理。其他账号、真实图片质量、长期稳定性和 Chrome 原生桥接未完成实机验证。OpenAI 开源接入文档目前只明确列出符合资格的 Plus / Pro 可使用计划额度。Business / Team 成员经此路径使用自己的额度尚未获得官方确认；组织策略拒绝不等于套餐资格结论。界面在授权前告知，并保留错误码与 Request ID 便于排查。
- 授权码过期或失效时可重新发起授权；首次兑换失败保留本机加密的应用注册信息。连接测试修复了上游 SSE 缺少 `Content-Type` 时的误报。账户、模型和 API 方案均由用户明确选择。具体安装、注销和组织策略说明见 [ChatGPT 登录说明](CHATGPT_LOGIN.md)。

## 验证范围

本版回归采用隔离 Edge、生成页面和模拟上游响应；真实翻译速度、准确率及不同账号的计划额度无法由合成测试证明。最终构建的逐文件校验与本轮测试结果见 [发布记录](STORE_SUBMISSION_0.9.0.md)。历史 0.8.16 及各开发版的测试记录保留在各自版本文件中。

完整本地回归 21 份报告共 513 项通过、0 项失败，覆盖默认设置、可关闭的 Windows 安装引导、沉浸式定位、文档与论文阅读、模型切换及打包审计。隔离 Chromium 中另有两次真实 MyMemory 固定短句请求得到中文译文；单次样本不能代表普遍速度。Chromium 151 报告英译中本地模型可下载，但在全新测试配置中等待 180 秒仍未完成下载，因此尚未验证真实本地模型译文；该场景会立即使用 MyMemory 回退。
