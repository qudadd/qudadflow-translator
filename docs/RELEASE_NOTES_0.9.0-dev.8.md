# QudadFlow Translator 0.9.0-dev.8（本地开发版）

## 本次修复

- 官方 Responses API 返回了有效的 SSE 流与 `response.completed`，但缺少 `Content-Type` 响应头时，原连接测试误报 `INVALID_RESPONSE`。现在按响应体中的 SSE 事件解析，并仍要求完成事件才返回成功；空响应、非 SSE 内容与提前断流继续报错。
- 已授权账号的上游模型目录可能提供文本输入能力，却不声明输出类型。文本筛选现在保留这些模型，并明确显示输出能力未知。
- 读取上游模型后将列表滚动到可见位置。ChatGPT 账号和普通 API 都要手动选中模型，再点击“填入此模型”；连接测试与保存设置仍需分别执行。

## 验证

- 本机授权的个人账号从官方目录读取到 8 个模型，并用 `gpt-6.1-sol` 对固定短句完成一次真实文本推理。诊断只记录模型数量、耗时和输出长度，不记录账号标识、凭据或译文。
- 本机宿主 29 项自动检查、隔离 Edge 设置页 15 项检查及普通 API 模型选择 23 项检查通过，覆盖缺失 `Content-Type`、无效流式正文、两种连接的手动模型选择、连接测试和账号隔离。
- 网页、沉浸式翻译、文档、论文、图表、三篇 PDF 样本及构建流程共 20 套 506 项检查通过。合并运行时 PDF 窄屏候选预览有一项等待超时；该套单独重跑 29/29 通过。长时间稳定性、图片质量及其他账号资格仍需继续验证。

这是本地开发版，尚未发布到浏览器商店。安装与资格说明见 [ChatGPT 登录说明](CHATGPT_LOGIN.md)。
