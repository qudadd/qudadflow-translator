## English listing text

QudadFlow Translator provides immersive webpages, nearby selection translation and document reading with your chosen API. Traditional machine translation and AI both support base translation: Google Cloud Translation, DeepL, Microsoft Translator, OpenAI-compatible Chat Completions/Responses, custom JSON and an optional limited MyMemory trial.

Read PDF, Word DOCX, TXT and Markdown in place, in original-layout comparison, or as paired paragraphs. PDF retains original page proportions, images and charts. Word renders tables, embedded pictures and margins in the browser; complex Word layout/fonts may differ. Long or unsupported text retains its original with a clickable full translation. Translate a page or all pages, stop/resume and export bilingual TXT.

The optional bottom AI workflow extracts document pictures, crops PDF charts or captures a whole page. Preview or download locally, then click to translate image text and explain charts using a separately saved vision AI configuration. Body translation can continue using a traditional provider. Selected images are sent only after an analysis click. Review AI text/numbers against the original. No chart redrawing or automatic scanned-page text replacement is included.

Up to 20 named configurations and keys stay in browser-local storage. Files parse locally. Body translation sends extracted text; optional AI analysis sends selected images to the chosen provider. Original document files/passwords are not uploaded to translation APIs. No developer proxy, ads, telemetry or remote executable code.

Maximum 25 MB/document, 300 pages/reading sections, one million text characters; picture workflow supports 20 images/24 MB with bounded resolution. Scanned body translation needs external OCR. Export is bilingual TXT, not layout-preserving PDF/DOCX. Chromium-based Edge 125+ required. Interface language: Simplified Chinese. Provider accounts, charges, quotas and retention terms apply. No unlimited free API is promised.

## 简体中文详细说明

QudadFlow Translator 提供网页沉浸式双语阅读、就近划词翻译和文档阅读。传统机器翻译与 AI 均提供基础翻译，支持自带 Google、DeepL、Microsoft、OpenAI 兼容、自定义 JSON 接口及可选 MyMemory 有限试用。

PDF、Word DOCX、TXT、Markdown 支持沉浸原位、原版左右对照、段落对照。PDF 保持原页比例、图片和图表位置；Word 在浏览器中保留表格、嵌入图片和页边距，复杂排版与字体可能不同于 Microsoft Word。长译文放不下或遇特殊排版时保留原文，点击查看完整译文。支持当前页/全文、停止续译与双语 TXT 导出。

最下方 AI 图文工作流可提取文档图片、框选 PDF 图表或提取整页。本地预览与下载，点击分析后才把所选图片发送给单独保存的视觉 AI 配置，翻译其中的文字并解释图表；正文仍可使用传统接口。AI 文字及数值需核对原图，不重绘图表或自动替换扫描页文字。

最多保存 20 个具名 API 方案，密钥保存在浏览器本地。文档本地解析，正文翻译发送提取文字，可选 AI 发送所选图片，不上传原始文档文件或密码。无开发者代理、广告、遥测或远程可执行代码。

限制：每文档 25 MB、300 页/阅读分段、100 万字符；图文工作流最多 20 张/24 MB、分辨率受限。扫描正文需先外部 OCR；导出为双语 TXT，不生成保留版式的 PDF/DOCX。最低 Edge Chromium 125，界面简体中文。服务商账号、费用、额度及保留条款各自适用，不承诺无限免费接口。
