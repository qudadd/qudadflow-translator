# 0.9.9 三平台发布记录

2026-11-10，准备记录。此版修复 Chrome **Red Titanium** 指出的 PDF.js 协议拼接写法，两个模块同步修改。GitHub 发布及两商店上传／提交结果将在实际操作后更新；准备完成不代表已提交或审核通过。

内部版本和显示版本均为 0.9.9。三个平台计划使用同一份经过审计的运行 ZIP，并在 GitHub 附带源码 ZIP、审计和 SHA256 清单。历史 0.9.8 标签与附件保持原样。

Chrome 后台在用户重新验证身份后确认 0.9.8 已于 2026-11-10 被拒；用户邮件提供具体 Red Titanium 引用和被标记代码。Edge 后台本次刷新确认 0.9.8 Live。具体问题及修复见[代码可读性说明](CHROME_READABILITY_0.9.9.md)。

中英文商店简介沿用[0.9.8 英文](store-description-en-0.9.8.txt)和[中文](store-description-zh-0.9.8.txt)，论文深度处理仍为定位。审核说明针对本次修复更新；独立 Windows 连接程序沿用 0.9.2。验证结果见 [VERIFICATION_0.9.9.md](VERIFICATION_0.9.9.md)。
