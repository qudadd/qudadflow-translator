QudadFlow Translator Privacy Policy

Version 0.4.4 · Effective date: October 21, 2026

This policy explains how QudadFlow Translator processes information when you use the Microsoft Edge extension. Developer and privacy contact: lcf1249288484@outlook.com.

Information processed

After you start a translation, the extension reads your selected text or visible text from the current webpage. It sends the text, source and target languages, and the authentication and configuration fields required by your selected API directly to the endpoint you configure. Depending on the API, the request can also include a model name, translation instructions, paragraph markers, and custom request fields or headers.

The extension does not automatically collect browsing history or translate pages in the background. Page extraction skips editable controls, hidden content, extension translations, and content marked to be excluded. Text that you explicitly select can still be sent when you request selection translation.

Translation providers

QudadFlow Translator does not operate a translation server or proxy. You choose the API provider and endpoint, including Google Cloud Translation, DeepL, Microsoft Translator, an OpenAI-compatible service, or a custom JSON service. That provider receives your translation requests and applies its own privacy, retention, security, and billing terms. Choose a trusted endpoint; use HTTPS for remote services.

Provider privacy information: Google, DeepL, and Microsoft. For other endpoints, consult the provider you configure.

Local storage and API keys

Your API key, endpoint, model, language preferences, and custom API settings are saved in the browser's extension local storage. They are not synchronized by this extension and are not sent to the developer. API keys and custom authentication fields are sent to your configured endpoint to authenticate requests. Switching providers in the settings page keeps separate temporary connection drafts and does not automatically reuse another provider's key.

Translation results are displayed in the current page and are not saved in extension storage. Immersive translations are inserted into the webpage, where the webpage's scripts may be able to read them. Restore the original page or reload it to remove the inserted translations.

For faster repeated reading, the service worker may keep successful source-and-result pairs in memory, with a five-minute reuse window and a limit of 128 entries and 250,000 combined characters. Expired entries are removed on the next cache lookup. This cache is not written to disk, is cleared when settings change, and may disappear when the browser stops the worker. Connection tests bypass the cache. No persistent translation history is maintained by the extension.

Permissions

activeTab and scripting access the current page and inject the bundled translation interface after an extension action. Storage saves your API settings and preferences locally. Context menus provide translation commands in the browser's context menu. Optional host access permits requests to the HTTP(S) API domain you configure. If you enable the selection button for a site, Edge registers the bundled content script for that site's HTTP(S) scheme and host on all ports. The script only shows a button after text is selected; selecting text alone does not send it. Disabling the setting stops the button on open pages and unregisters future loading. Edge retains the granted permission until you revoke it in extension settings.

Advertising, analytics, and remote code

The extension contains no advertising, tracking, analytics, or telemetry. The developer does not sell personal information. All executable extension code is bundled locally. API responses are handled as text data and are never executed as code.

Your choices and deletion

You can change your endpoint and credentials in the settings page, revoke site permissions through Edge's extension settings, restore translated pages, or remove the extension. Removing it deletes its local extension storage. These actions do not delete data already retained by an API provider; contact that provider about deletion and other privacy requests.

Contact and changes

For support or privacy requests, email lcf1249288484@outlook.com. Material changes to this policy will be reflected in its effective date and the extension's release information.
