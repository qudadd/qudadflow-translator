# QudadFlow Translator 0.9.3

论文与文档中的图表现在使用独立解析浮窗，减少工作台拥挤；Python/R 样式复刻新增可直接试跑的演示路径与专用代码框。

- 在图表总览点击“打开解析浮窗”，并排查看原图与当前解读。支持上一张、下一张、最大化及 Esc 返回；保留选择、结果、语言页签、滚动位置和正在接收的回答。窄屏纵向排列。
- 解读、Python、R 分页呈现。代码框提供行号、一键复制、下载、自动换行和放大查看；剪贴板不可用时自动选中代码供手动复制。运行说明、规格和数据模板默认折叠。
- 折线、散点、分组柱图及通用多面板共用一份 JSON 规格生成 Python/R，切换语言不重复请求模型。包含复杂图层的图仍提供完整自定义代码。
- 通用模板支持 `--style-demo`，无需 CSV 即可查看字体、配色、图例、布局和标注，导出 PNG/PDF/SVG。合成演示值与演示输出明确标记；形式和风格验收不要求数值还原。
- 可导入本地试运行图，明确点击“对照原图修订”后发送原图、试运行图与规格。修订聚焦视觉差异并保留已有数据映射、分组及区间含义。
- 扩展只生成代码，不执行代码或安装依赖。继续使用既有 0.9.2 Windows 连接程序，本次没有更新连接程序。

更新前的同一功能代码已完成 548 项回归，0 项失败；覆盖网页、阅读器、三篇本地 PDF 流程、原生浮窗、代码复制与放大、两种语言共享规格、视觉修订及打包负面测试。隔离 Edge 的 AI 接口使用本地模拟服务；这不表示真实模型对任意论文的识别质量已经验证。Python/R 样式示例另在真实解释器中完成试跑，验收显示层次、图例与导出，不核对论文数值。
