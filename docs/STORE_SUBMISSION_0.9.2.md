# QudadFlow Translator 0.9.2 发布记录

此版本在 0.9.1 基础上加入按需安装引导及启动、翻译、原生调用性能优化。0.9.1 历史发布资料保留在原文件中。

| 平台 | 当前状态 |
| --- | --- |
| 本地 | 0.9.2 的 272 个运行文件已同步并逐文件校验，旧目录已备份；现有 Windows 连接程序也已更新并通过原生消息检查。浏览器中的扩展仍需重新加载。 |
| GitHub | 尚未发布 0.9.2 |
| Edge Add-ons | 尚未上传或送审 0.9.2；0.9.1 工作期间已发起取消旧 0.8.16 审核，取消完成状态需后台核对 |
| Chrome Web Store | 尚未上传或送审 0.9.2；上一轮后台已上线版本为 0.8.16 |

本版本新增可选 `downloads` 权限。仅用户在 ChatGPT 设置中点击下载时申请，用于下载并跟踪本次连接程序文件；不查询其他下载或浏览历史。无需此功能的用户不被要求授予该权限。连接程序始终独立于商店运行包，扩展不执行下载的文件。

ChatGPT 登录保持预览标识；Windows x64 一次性安装、当前安装器未签名及 Team / Business 资格未确认的说明均保留。商店送审与审核通过分别记录，不将本地测试当作商店发布。

## 验证

完整回归矩阵的最终结果为 **21 份报告、518 项通过、0 项失败**。运行中发现 iframe 重载后的旧节点检查及 PDF 连续阅读滚动竞态，修复后重跑对应检查；原始失败报告保留，最终汇总引用通过的复测报告。覆盖网页功能、沉浸式布局、文档与 PDF、模型与配置、论文和图表、表格导出及可复现打包。

补充验证：隔离 Edge 的 ChatGPT 界面与按需下载流程 25／25，原生宿主 30／30，翻译性能与取消隔离 11／11，真实 Windows DPAPI 兼容及性能 5／5，安装器完整性与路径负面测试 4／4。除本机已有连接程序的状态检查外，账号和 API 流程均使用合成数据，不访问真实模型，也不等同于所有浏览器、网站或账号均已验收。

性能对比基线为 Git 标签 `v0.9.1`。模拟服务下的 8 个重复并发请求从 8 次上游调用降为 1 次，204 ms 降为 73 ms；真实 Windows 上合成凭据的 DPAPI 单次解密中位数从 1,137 ms 降为 52 ms。这些数据只反映被测开销，详见[性能报告](PERFORMANCE_0.9.2.md)。
