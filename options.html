网页沉浸式快捷键 本地保存

默认 Shift+A。点击“录制快捷键”后按组合键即保存，Esc 取消；也可手动输入后按 Enter 或点击保存。支持 Ctrl、Alt、Shift、Meta 搭配字母、数字、方向键、Space、Enter 或标点（如 Ctrl+/），F1–F12 可单独使用。仅在已授权网页正文触发；输入框与编辑器内正常输入，Ctrl+A 保留全选。浏览器或系统保留的组合键可能无法录制或触发。可在“网站与 API 访问权限”一次授权所有网站。

自定义 JSON 映射

替换占位符后必须是 JSON。占位符要作为 JSON 值使用，例如 "prompt": {{text}}，可用 text、model、sourceLanguage、targetLanguage、context、apiKey。

使用点号和数组下标，例如 data.translation 或 choices[0].message.content。

网站与 API 访问权限

保存时会请求访问你填写的 API 域名。扩展只会向该域名发送翻译请求。

默认按需授权，浏览器会记住已授权的站点。也可一次允许所有 HTTP/HTTPS 网站，减少切换论文、载入原图和 API 时的确认。此权限允许扩展读取这些网站；只有你操作翻译或分析时才发送相应内容，不会自动启用全站划词。
