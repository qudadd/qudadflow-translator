QudadFlow Translator设置

配置第三方翻译 API，密钥只保存在本浏览器的扩展存储中。

API 连接

可填写 OpenAI、DeepSeek、智谱、通义、Moonshot、硅基流动、Ollama 等兼容接口的完整地址。

OpenAI 兼容接口可填完整地址，或填到 /v1；自定义 JSON 接口请填实际 POST 地址。

扩展只会按接口类型把密钥发送到指定端点，不会上传到本项目服务器。

也可以在自定义请求头中填写 Ocp-Apim-Subscription-Region。

可用占位符：{{apiKey}}、{{model}}。例如 {"X-API-Key":"{{apiKey}}"}。

翻译偏好

自定义 JSON 映射

替换占位符后必须是 JSON。占位符要作为 JSON 值使用，例如 "prompt": {{text}}，可用 text、model、sourceLanguage、targetLanguage、context、apiKey。

使用点号和数组下标，例如 data.translation 或 choices[0].message.content。

API 域名访问权限

保存时会请求访问你填写的 API 域名。扩展只会向该域名发送翻译请求。
