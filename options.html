API 方案与模型

配置仅本地保存

默认机器翻译无需配置或安装本地程序。只有主动选择 ChatGPT 计划时，才需要一次性连接程序和官方账号授权。

可填写 OpenAI、DeepSeek、智谱、通义、Moonshot、硅基流动、Ollama 等兼容接口的完整地址。

最多保存 20 个方案，每个方案保留自己的 API Key。选择方案后，点击下方“保存设置”才会应用。

获得官方计划授权后，QudadFlow 使用所选账号自己的额度，不共用管理员账号或 API Key。默认机器翻译无需登录或额外设置；只有主动选择 ChatGPT 计划才需要本地连接程序保护登录凭据。

Team / Business 授权前请先了解：OpenAI 开源接入说明目前只明确列出符合资格的 Plus / Pro 可使用计划额度。Team / Business 成员的个人 ChatGPT Work / Codex 额度能否用于本扩展，尚无官方确认；组织策略拒绝也无法单独判定套餐资格。若官方提示“组织尚未启用此应用”，请保留错误码和 Request ID，停止重复授权。默认机器翻译可直接使用。

Team / Business 授权失败怎么办？

普通成员：若官方页面显示“组织尚未启用此应用”，请停止重复授权，将错误码和 Request ID 交给组织管理员；页面没有自动返回时，可在此取消登录。默认机器翻译仍可使用。

管理员：先查看 OpenAI Admin Console 的 External access。若 QudadFlow 不在应用列表，当前页面没有可直接针对本应用放行的项目；即使“身份”和“已连接的应用”默认允许，也不能据此确认计划额度权限。请勿为此直接放宽全组织默认设置。凭诊断信息向 OpenAI 支持确认 Business 成员额度是否支持此开源授权，以及未列出应用时的审批办法。只有官方确认可用并给出配置方式后，才按最小范围配置；成员仍需各自授权。

额度资格：若连接测试返回 subscription_sharing_user_not_eligible，所选账号、工作区或策略无法使用此接入，请勿反复重试。切换账号或工作区时，请选择“添加账号或工作区并授权”，不要复用原工作区的注册。

管理 ChatGPT 用量与应用访问。达到限额时会暂停，不会自动切换付费 API。

本地连接程序未就绪（仅 ChatGPT 计划）

默认机器翻译无需此程序。Windows x64 商店版请下载本地连接程序，解压后双击 Install-Bridge.cmd，再返回此页点击“重新检测”。安装仅针对当前 Windows 用户，支持 Edge 和 Chrome。
